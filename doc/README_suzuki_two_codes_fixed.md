# Suzuki 曲線から作る同一パラメータの2つの AG 双対符号

## 目的

同じ Suzuki 曲線、同じ有限体、同じ評価点集合 `D` を固定し、因子だけを変えて

\[
G_1=mP_\infty+P_1-Q,\qquad G_2=mP_\infty+P_2-Q
\]

を作る。両因子は同じ次数を持つ。プログラムは

\[
C_i=C_L(D,G_i)^\perp
\]

を構成し、同じパラメータになること、固定した座標順序で符号空間が異なること、両方が同じ ECP によって復号できることを検査する。

## 曲線と評価点

有限体は GF(2^12)、既約多項式の候補は `0x1053`。初期化時に 1 が全ての非零元を巡ることを確認する。

Suzuki 曲線は

\[
y^8+y=x^2(x^8+x)
\]

で、種数は `g=14`。アフィン有理点を列挙し、3本の完全ファイバーを予約する。評価集合 `D` はその3ファイバーを除いた全アフィン有理点で、既定値では `n=5864`。

## 2つの因子と符号パラメータ

既定値 `m=60` では

\[
\deg G_1=\deg G_2=60.
\]

`deg G > 2g-2` なので Riemann--Roch により

\[
\ell(G_i)=\deg G_i-g+1=60-14+1=47.
\]

また `deg G_i < n` なので評価写像は単射であり、

\[
C_L(D,G_i):[5864,47, d\ge 5864-60=5804]
\]

となる。したがって双対符号は

\[
C_i=C_L(D,G_i)^\perp:[5864,5817, d\ge 60-2\cdot14+2=34].
\]

ここで距離は設計距離の下界であり、厳密な最小距離を計算した値ではない。

## 共通 ECP

両方の符号に同じ補助因子

\[
A=30P_\infty-Q,\qquad B=30P_\infty
\]

を使う。

\[
A+B=60P_\infty-Q,\qquad G_i-(A+B)=P_i\ge0.
\]

したがって `A+B <= G_i` であり、点ごとの積について

\[
C_L(D,A)*C_L(D,B)\subseteq C_L(D,G_i)=C_i^\perp
\]

が成立する。プログラムは各基底ベクトルの全ての積を有限体上で作り、実際に包含を検査する。

さらに

\[
\ell(A)=29-14+1=16>3,
\]

\[
d(C_L(D,B)^\perp)\ge 30-2\cdot14+2=4>3.
\]

よってこの ECP は最大3誤りの訂正条件を満たす。

復号器は受信語 `r` から ECP シンドローム写像の核を計算し、その共通零点を誤り位置として求める。続いて `L(G_i)` の評価行列から誤り値を解き、最後に全パリティ検査を再確認する。

## 異なる符号であることの検査

`G1-G2=P1-P2` について `ell(P1-P2)` を計算する。次数0の因子 `E` について `ell(E)>=1` なら主因子であるため、`ell(P1-P2)=0` は非主因子性を示す。

さらに、`L(G1)` と `L(G2)` の評価行空間を同じ座標順序で直接比較する。既定値では一致しない。

これは固定した評価点ラベルの下で2つの符号空間が異なることを示す。一方、任意の座標置換・非零座標倍率を許すモノミアル同値性までは判定していない。したがって「モノミアル非同値」とは結論しない。

## ビルドと実行

```sh
gcc -O2 -std=c11 suzuki_two_codes_fixed.c -o suzuki_two_codes
./suzuki_two_codes
```

引数は `G-degree`, `error-count`, `seed`。

```sh
./suzuki_two_codes 60 3 123
./suzuki_two_codes 61 3 7
```

`G-degree` は既定の ECP 因子 `A+B` の次数60以上、基底上限 `RMAX` に対して `m+8 <= RMAX` の範囲で指定する。

## 検証結果

ASan/UBSan を有効にしてコンパイルし、次を確認した。

- `m=60, t=3`: `ell(G1)=ell(G2)=47`、双対符号 `[5864,5817,d>=34]`、両符号で3誤りを訂正し元の符号語を完全復元。
- `m=61, t=3`: `ell(G1)=ell(G2)=48`、双対符号 `[5864,5816,d>=35]`、両符号で3誤りを訂正し元の符号語を完全復元。
- `m=60, t=0`: 両符号で誤りなしの復号を確認。

乱数シードを固定した実験結果であり、全ての誤りパターンに対する網羅試験ではない。
