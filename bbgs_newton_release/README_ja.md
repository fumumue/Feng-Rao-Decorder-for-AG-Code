# 一般化BBGS曲線：有理点・Newton基底出力ツール

## 目的

`bbgs_newton.c` は、一般化BBGS曲線について次の処理を行う独立した前処理プログラムです。

1. 項数 `T=4..10` と有限体パラメータ `q,m` から曲線を生成する。
2. 必要なら `a,b` を総当たりし、各Newton種数について有理点数が最大の候補を表示する。
3. 指定された有限体上のアフィン有理点を全列挙する。
4. Newton多角形・辺・格子長・重みベクトルを計算する。
5. アフィン部分が滑らかであること（この族では `F_Y=1`）と、各辺のface polynomialが重根を持たないことを検査する。
6. 単一の有理場所に対応するprimitive edgeについて、`L(MP)` のNewton単項式基底を生成する。
6. `M >= 2g-1` のとき、基底数がRiemann–Rochの次元 `M+1-g` と一致するか検査する。
7. 点一覧・基底・パラメータをTSV/TXTで保存する。

この段階では符号化・シンドローム計算・復号は行いません。既存の復号器に接続する前の、曲線と基底データを作るためのツールです。

## 曲線のパラメータ

項数は

\[
T=1+a+b,\qquad a+b=T-1,\qquad \gcd(a,b)=1
\]

です。曲線は標数2で次の式を使います。ここで `c=a+b` です。

\[
X^{q^{c-1}}
+\sum_{k=0}^{b-1}X^{q^{c-1}-q^k}Y^{q^{a+k}}
+\sum_{k=0}^{a-1}X^{q^{c-1}-q^{b+k}}Y^{q^k}=0.
\]

`q=2^r` とし、係数体 `GF(q^c)=GF(2^(rc))` が探索体 `GF(2^m)` に含まれる必要があるため、

\[
rc\mid m
\]

を検査します。現在の有限体テーブルは `2 <= m <= 11` です。

### 自動選択

`--a` と `--b` を指定しない場合、`a+b=T-1` かつ `gcd(a,b)=1` の組をすべて調べます。

出力表には各Newton種数について、

- その種数で有理点数が最大の `(a,b)`
- 現在のNewton基底生成方式が扱える候補のうち、有理点数が最大の `(a,b)`

を別々に表示します。

基底を実際に出力する既定の選択は、Newton faceの非退化性検査に通り、primitive edgeを少なくとも1本持つ候補の中で有理点数が最大のものです。特定の種数を選ぶ場合は `--genus G` を指定します。ある種数にprimitive edgeを持つ候補がない場合、現段階ではその種数の基底出力はできないと明示して停止します。

`--a A --b B` を指定すると自動探索を行わず、その組を使います。

## ビルド

```sh
cc -O2 -std=c11 -Wall -Wextra -Werror -o bbgs_newton bbgs_newton.c
```

または

```sh
make
```

## 実行例

```sh
# 項数4、q=2、GF(2^3)。点・基底・メタデータを保存
./bbgs_newton --terms 4 --q 2 --m 3 --out data_t4

# 項数10、q=2、GF(2^9)。大きな基底を出力
./bbgs_newton --terms 10 --q 2 --m 9 --out data_t10

# 項数6、q=2、GF(2^10)でNewton種数120の候補を選ぶ
./bbgs_newton --terms 6 --q 2 --m 10 --genus 120 --out data_g120

# a,bを固定して曲線を生成
./bbgs_newton --terms 6 --q 2 --m 5 --a 2 --b 3 --out data_a2_b3

# 極次数Mを変更し、edge E0だけの基底を表示
./bbgs_newton --terms 4 --q 2 --m 3 --M 12 --edge 0 --dump-basis

# 有理点を標準出力にも表示
./bbgs_newton --terms 4 --q 2 --m 3 --list-points
```

## オプション

| オプション | 意味 |
|---|---|
| `--terms T` | 項数4〜10 |
| `--q Q` | `q`（2の冪） |
| `--m M` | 探索体 `GF(2^m)`、2〜11 |
| `--a A --b B` | `a,b`を固定。正整数、互いに素、和が`T-1` |
| `--genus G` | そのNewton種数で基底生成可能な候補から点数最大の曲線を選択 |
| `--poly P` | 有限体の原始多項式。省略時は内蔵表 |
| `--M N` | 基底の極次数上限。省略時は `2g-1` |
| `--edge E` | 対象のNewton edge。省略時は全primitive edge |
| `--out PREFIX` | `PREFIX.points.tsv`、`PREFIX.basis.tsv`、`PREFIX.meta.txt` を出力 |
| `--list-points` | 有理点を標準出力に表示 |
| `--dump-basis` | 基底単項式を標準出力に表示 |

## 出力ファイル

### `PREFIX.points.tsv`

- `x`, `y`: 有限体の整数表現による座標
- `eval_nonzero_xy`: `x != 0 && y != 0` なら1。Laurent単項式に負の指数がある場合、この値が0の点は評価に使えません。

このBBGS曲線では、座標軸上のアフィン点は原点だけです。

### `PREFIX.basis.tsv`

- `edge`: 対応するNewton edge番号
- `pole_order`: その場所での極次数
- `i`, `j`: 単項式 `x^i y^j` の指数
- `monomial`: 単項式の表示

### `PREFIX.meta.txt`

パラメータ、Newton種数、有理点数、Riemann–Roch次元検査の結果を記録します。

## 基底生成の範囲と制限

各Newton edgeの格子長が1である場合、そのedgeは単一の有理場所に対応するprimitive edgeとして扱い、他の辺で極を持たない条件と対象辺の極次数上限から単項式代表を選びます。同じ極次数に複数の単項式がある場合は、負の指数を含まない代表を優先します。

`M >= 2g-1` ならRiemann–Rochにより

\[
\ell(MP)=M+1-g
\]

なので、生成した代表数がこの値と一致するかを検査します。既定値は `M=2g-1` です。

曲線族のアフィン部分は、第二群の `k=0` の項が `Y` であり、他の `Y` 指数がすべて2の冪なので、標数2で `F_Y=1` となります。したがってアフィン部分に特異点はありません。さらに各Newton辺のface polynomialを一変数多項式に直し、その導関数との最大公約数が1であることを確認します。全辺でこの検査に通った場合に `toric nondegeneracy=PASS` とし、Newton多角形の内部格子点数を曲線の種数として使用します。

格子長が1より大きい辺については、複数の枝や高次数の場所の分解が必要です。この版ではその枝ごとの基底をまだ出力しません。これは「その辺に有理点がない」という意味ではなく、枝の分解を含む基底生成が未接続という意味です。

また、`M < 2g-1` を指定した場合は候補単項式を出力しますが、Riemann–Roch次元による完全性検査は行いません。

これらは記載した有限個の条件に対する実行検査であり、すべてのパラメータ・すべての枝の基底を証明したものではありません。
