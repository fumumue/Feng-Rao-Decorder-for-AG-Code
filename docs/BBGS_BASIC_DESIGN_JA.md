# BBGS曲線版ベーシックアルゴリズム：設計・計算ノート

## 1. 採用したBBGS塔

初期実験は、原論文のBBGS塔から次を採用する。

- 標数：p=2
- q=2、有限体の大きさ：ℓ=q^3=8
- n=3=j+k、j=1, k=2、gcd(j,k)=1
- 有限体：K=F_8=F_2[a]/(a^3+a+1)

BBGSの再帰式：
Tr_j(x_{i+1}/x_i^(q^k)) + Tr_k(x_{i+1}^(q^j)/x_i) = 1.

したがって最初の拡大 E2=F_8(x,y) の式は

Tr_1(y/x^4) + Tr_2(y^2/x) = 1.

**重要な訂正：** 初期メモにあった y/x^2 は誤記だった。BBGS原論文の式(9)、塔の式(23)に従うと分母は x^(q^k)=x^4 である。本実装は正しい式に修正した。

ここで Tr_r(z)=z+z^2+...+z^(2^(r-1))。分母を払った多項式形は

y + x^3 y^2 + x^2 y^4 = x^4.

## 2. 有理評価点の計算結果

x∈F_8^× の各値について、y∈F_8 を全列挙し、BBGSのトレース式を直接評価した。

| x | 条件を満たす y | 個数 |
|---:|---|---:|
| 1 | 1, 3, 5, 7 | 4 |
| 2 | 1, 3, 4, 6 | 4 |
| 3 | 2, 3, 6, 7 | 4 |
| 4 | 1, 2, 5, 6 | 4 |
| 5 | 2, 3, 4, 5 | 4 |
| 6 | 1, 2, 4, 7 | 4 |
| 7 | 4, 5, 6, 7 | 4 |

よって、評価に使える相異なる有理場所をこの構成から n=7×4=28 個得た。各ファイバーに4点あることは、BBGS原論文 Proposition 2.5 の「非零 β に対する [x=β] の完全分解」と一致する。

## 3. 種数と1点除数の数値設計

BBGS原論文 Corollary 2.7 の基本関数体の種数公式は

g = ((q^n-2)(q^(j-1)+q^(k-1)-2)+(q^n-q))/2.

q=2,n=3,j=1,k=2 を代入すると

g = ((8-2)(1+2-2)+(8-2))/2 = 6.

原論文 Proposition 2.6 によると [u=∞] の上には q-1 個の場所がある。今回は q=2 なので1個であり、これを Q とする。原論文 Proposition 2.8 の記述から、この場所では x は零、y は極となる。評価点はすべて x≠0 のファイバーから選んでいるので、Q は評価点集合と交わらない。

1点除数を G=mQ, m=11 と選ぶ。2g-2=10 なので m>2g-2 を満たし、Riemann–Rochの定理から

ℓ(G)=deg(G)+1-g=11+1-6=6.

また deg(G)=11<n=28 なので評価写像は単射である。得られる評価型AG符号の数値設計は

[n,k,d] = [28,6, d≥17].

ここで d≥n-deg(G)=17 は設計下界であり、最小距離を実測した値ではない。この下界から通常の一意復号半径として少なくとも

t=floor((17-1)/2)=8

を設計できる。

## 4. 実装状況

- [x] F_8 の加減乗除・逆元・Frobenius・相対トレース
- [x] BBGSの正しい再帰式（最初の一段）の直接評価
- [x] 28個の有理評価場所の列挙と各ファイバー4点の検査
- [x] 種数 g=6 の理論値を原論文の公式から計算
- [x] 1点除数 G=11Q のRR次元・符号長・距離下界・設計訂正半径の計算
- [ ] L(11Q) の具体的な関数基底の生成と独立性検査
- [ ] Q におけるWeierstrass半群／重み列の厳密計算
- [ ] ベーシック（Feng–Rao型）復号器
- [ ] 誤り訂正実験と結果記事

**注意：** 現段階で完了した「RR計算」は ℓ(11Q)=6 という次元計算と符号パラメータの設計までである。具体的な6本の基底関数やWeierstrass半群はまだ計算していない。したがってベーシック復号の重み順序・訂正保証まで完成したとは扱わない。

## 5. ビルドと実行

bbgs_gf.c は有限体演算と有理点列挙を行う。

~~~sh
gcc -std=c11 -O2 -Wall -Wextra -Werror bbgs_gf.c -o bbgs_e2
./bbgs_e2 --self-test
./bbgs_e2
~~~

自己テストでは逆元、28点の列挙、および各 x≠0 のファイバーが4点であることを検査する。
